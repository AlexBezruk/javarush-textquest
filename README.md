# 🧙‍♂️ Text Quest — Интерактивная игра на Java

Веб-приложение-квест, реализованное на Java с использованием сервлетов, JSP и JSTL.  
Игрок проходит серию вопросов, где каждый выбор влияет на развитие сюжета.  
Проект создан в рамках финального задания модуля **Java Professional** на JavaRush.

---

## 🚀 Возможности

- 📖 **Интерактивный сюжет**: ветвящиеся вопросы, ведущие к победе или поражению
- 🧑‍💼 **Идентификация игрока**: имя и статистика сохраняются в сессии
- 🔁 **Перезапуск игры**: возможность начать заново после завершения
- 🧪 **Тестирование логики**: покрытие бизнес-логики через JUnit
- 🌐 **Веб-интерфейс**: сервлеты + JSP + JSTL для отображения и обработки
- 🖥️ **Совместимость с Tomcat 9**: легко разворачивается локально или на сервере

## ⚙️ Как работает программа

Приложение моделирует текстовый квест, в котором игрок проходит серию вопросов.  
Каждый шаг зависит от предыдущего выбора, а логика переходов реализована через Java-сервлеты и хранится в сессии.

### 🧑‍💼 1. Приветствие
- Игрок попадает на стартовую страницу (`index.jsp`)
- Вводит имя, которое сохраняется в `HttpSession`
- Отображается предыстория квеста

### ❓ 2. Вопросы и ответы
- Каждый вопрос представлен объектом `Question`, содержащим текст и список `Answer`
- Ответы ведут к следующему вопросу, победе или поражению
- Переходы обрабатываются через `QuestServlet`

### 🏁 3. Завершение
- Если игрок побеждает или проигрывает, отображается финальное сообщение
- Предлагается начать игру заново, сбросив сессию

---

## 🧩 Логика квеста

- Вся структура квеста описана в классе `Quest.java`
- Вопросы и ответы связаны через идентификаторы
- Переходы между вопросами реализованы как дерево решений
- Логика не зависит от UI и может быть протестирована отдельно

---

## 🧪 Тестирование

- Используется **JUnit 5** для проверки бизнес-логики
- Тесты находятся в `src/test/java`
- Проверяются:
    - Корректность переходов между вопросами
    - Победа и поражение
    - Сброс состояния
    - Обработка некорректных ответов
